### **🧠 今日深度思考 (Reflections)**
1.  **注释即命令**：意识到工具的 `Docstring` 并非简单的注释，而是 Agent 识别意图的“诱饵”。写好注释是控制 Agent 行为最精准的方式。
2.  **Agent 的思考闭环**：理解了 Agent 并不是直接运行代码，而是通过 `JSON 指令` 与系统通信。一个完整的任务可能需要多次“思考-动作-观察”的循环。
3.  **架构抉择：全能 vs 专精**：思考了工具堆叠导致的复杂性问题。结论是与其做一个臃肿的“全能工具箱”，不如构建“专精领域智能体”，通过分工和解耦来解决复杂问题。
4.  **连接外部世界**：探讨了 API 包装器与 **MCP (Model Context Protocol)** 的区别。意识到智能体的上限取决于它能连接多少外部资源，而 MCP 可能是未来的标准插座。
